# CityPulse

Сайт для повідомлень про проблеми міста. Усі користувачі бачать спільні позначки.

## Структура
- `client/` — сайт (HTML, CSS, JS)
- `server/` — сервер Express і API
- `.gitignore` — файли, які не потрібно завантажувати на GitHub

## Запуск на своєму комп'ютері
1. Встановіть Node.js LTS.
2. У терміналі:
   ```
   cd server
   npm install
   copy .env.example .env      (на Mac/Linux: cp .env.example .env)
   npm start
   ```
3. Відкрийте http://localhost:3000. Сервер сам віддає сайт.
Позначки зберігаються у файлі `server/data/reports.json`. Це лише для розробки.

## Фото
У формі є кнопки «📷 Сфотографувати» і «🖼️ З галереї». На телефоні перша відкриває камеру,
на комп'ютері обидві відкривають вибір файлу. Перед відправкою фото стискається до 1280 px
(JPEG), тому важить кілька сотень кілобайт. З базою PostgreSQL фото зберігаються в ній самій,
у файловому режимі лежать у `server/data/photos/`.
