# CityPulse: міські проблеми Чернівецької області

Сайт, де мешканці можуть повідомляти про міські проблеми (ями, освітлення, сміття, тротуари тощо), позначати їх на карті та надсилати фото. Усі повідомлення зберігаються на сервері й видно всім відвідувачам.

## Що знадобиться

- Windows 10 або 11
- Node.js версії 22.13 або новіша (рекомендовано LTS)
- VS Code (необов'язково, але зручно)
- Браузер Chrome або Edge

## Структура проєкту

```
citypulse
├── index.html
├── style.css
├── app.js
├── hero.jpg
├── README.md
├── _gitignore        (перейменуйте на .gitignore)
└── server
    ├── index.js
    └── package.json
```

## Крок 1. Встановіть Node.js

1. Відкрийте https://nodejs.org і завантажте версію **LTS**.
2. Запустіть інсталятор і натискайте **Next** до кінця, нічого не змінюючи.
3. Перезавантажте комп'ютер.
4. Перевірте установку. Відкрийте PowerShell і введіть:

   ```powershell
   node -v
   npm -v
   ```

   Має з'явитися номер версії Node.js, наприклад `v24.x.x`, і номер npm.

## Крок 2. Скопіюйте папку проєкту

1. Скопіюйте папку `citypulse` на новий комп'ютер (флешкою, через хмару або архівом).
2. Покладіть її, наприклад, у `Документи`, щоб шлях був `Документи\citypulse`.
3. Переконайтеся, що файл `hero.jpg` лежить поруч із `index.html`.
4. Перейменуйте `_gitignore` на `.gitignore`. Якщо Windows не дає цього зробити, відкрийте папку в Провіднику, увімкніть **Вид → Показати → Імена елементів** і повторіть.

## Крок 3. Відкрийте папку `server` у терміналі

1. Відкрийте PowerShell і перейдіть у папку сервера:

   ```powershell
   cd Документи\citypulse\server
   ```

   Або відкрийте `citypulse` у VS Code, потім **Terminal → New Terminal** і виконайте `cd server`.

2. Переконайтеся, що в рядку терміналу написано `...\citypulse\server>`.

## Крок 4. Встановіть залежності (лише один раз)

```powershell
npm install
```

Після завершення має з'явитися повідомлення без помилок. Попередження `deprecated` можна ігнорувати.

## Крок 5. Придумайте ключ адміністратора та запустіть сервер

Ключ адміністратора — це пароль, який ви вигадуєте самі. Наприклад: `Bukovyna2026x`. Запишіть його.

```powershell
$env:ADMIN_KEY="ваш_ключ"
npm start
```

Якщо все добре, з'явиться текст:

```
CityPulse працює: http://localhost:3000
```

Термінал має залишатися відкритим, поки ви користуєтеся сайтом.

## Крок 6. Відкрийте сайт

У браузері перейдіть за адресою:

```
http://localhost:3000
```

## Як користуватися

- **Додати повідомлення.** Натисніть «Повідомити», заповніть форму, оберіть місце на карті, за бажанням додайте фото, потім натисніть «Надіслати».
- **Режим адміністратора.** Натисніть кнопку з іконкою людини у верхньому правому куті, введіть ключ. Тоді можна змінювати статус проблеми (Нове, У роботі, Вирішено).

## Наступні запуски

Крок `npm install` повторювати не потрібно. Достатньо:

```powershell
cd Документи\citypulse\server
$env:ADMIN_KEY="ваш_ключ"
npm start
```

Щоб зупинити сервер, натисніть **Ctrl + C**.

## Доступ з інших комп'ютерів у мережі

Щоб інші пристрої в тій самій Wi-Fi мережі відкрили сайт, на вашому комп'ютері має працювати сервер, а в браузері на іншому пристрої потрібно вказати IP вашого комп'ютера, наприклад `http://192.168.1.10:3000`. IP можна дізнатися командою `ipconfig` (рядок «IPv4-адреса»). Можливо, доведеться дозволити Node.js доступ у брандмауері Windows, коли він запитає.

## Збереження даних

Усі повідомлення зберігаються у файлі `server\data\citypulse.db`, а фото — у `server\data\photos\`. Ця папка не потрапляє в Git (її ігнорує `.gitignore`). Щоб перенести дані на інший комп'ютер, скопіюйте папку `server\data` разом із рештою проєкту.

## Можливі проблеми

| Проблема | Рішення |
|---|---|
| `npm не є внутрішньою командою` | Встановіть Node.js і перезавантажте комп'ютер |
| `EADDRINUSE` | Порт 3000 зайнятий. Запустіть з іншим портом: `$env:PORT="3001"` і відкрийте `localhost:3001` |
| «Немає зв'язку із сервером» | Сервер не запущений. Запустіть `npm start` |
| Режим адміністратора не працює | Ключ має збігатися з тим, що задано в `$env:ADMIN_KEY` |
| `npm install` видає помилку про `better-sqlite3` | Переконайтеся, що використовується новий `server\index.js` і `package.json` без цієї бібліотеки |
