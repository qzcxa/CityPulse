# CityPulse

Сайт для повідомлень про проблеми міста. Усі користувачі бачать спільні позначки.

## Структура
- `client/` — сайт (HTML, CSS, JS)
- `server/` — сервер Express і API
- `.gitignore` — файли, які не потрібно завантажувати на GitHub

## Запуск на своєму комп'ютері
1. Встановіть Node.js LTS.
2. У терміналі:
   ```
   cd server
   npm install
   copy .env.example .env      (на Mac/Linux: cp .env.example .env)
   npm start
   ```
3. Відкрийте http://localhost:3000. Сервер сам віддає сайт.

Позначки зберігаються у файлі `server/data/reports.json`. Це лише для розробки.

## Фото
У формі є кнопки «📷 Сфотографувати» і «🖼️ З галереї». На телефоні перша відкриває камеру,
на комп'ютері обидві відкривають вибір файлу. Перед відправкою фото стискається до 1280 px
(JPEG), тому важить кілька сотень кілобайт. З базою PostgreSQL фото зберігаються в ній самій,
у файловому режимі лежать у `server/data/photos/`.

## Режим адміністратора
Змінювати статуси може тільки той, хто знає `ADMIN_KEY` з файлу `.env`.
На сайті натисніть «🔑 Режим адміністратора» (ліворуч унизу) і введіть ключ.
Звичайні користувачі бачать статус без можливості змінювати його.

## Справжня база даних (PostgreSQL)
1. Створіть безкоштовну базу на neon.tech і скопіюйте рядок підключення.
2. Додайте в `.env`: `DATABASE_URL=...`
3. Перезапустіть сервер. Таблицю `reports` він створить сам.

## Публікація в інтернеті
1. Завантажте проєкт на GitHub (файл `.env` не завантажуйте).
2. Створіть Web Service на Render: Root Directory `server`, Build `npm install`, Start `npm start`.
3. У змінних середовища Render задайте `ADMIN_KEY`, `DATABASE_URL` і `SEED_DEMO=0`.

Без `DATABASE_URL` на безкоштовному хостингу файл з даними буде стиратися.
